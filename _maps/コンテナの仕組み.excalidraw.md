# Excalidraw Data

## Text Elements
コンテナの仕組み ^t0000031

コンテナが、Linux カーネルのどの機能の上に、どの部品で作られているかを示すマップ。
下の段はオンプレでもクラウドでも同じ。説明ページ：[[コンテナの仕組み]] ^t0000032

カーネルの機能：Docker を支える Linux の4つの仕組み ^t0000033

ネットワークは名前空間の1つ（net）。CPU・メモリは cgroups で上限をかける資源。ストレージは書き込みの行き先の話。 ^t0000034

[[名前空間]]
プロセスから見える範囲を分ける ^t0000037

net：ネットワーク（[[Docker compose構成]] の図） ^t0000039

pid：プロセス番号（中では PID 1 から） ^t0000041

mnt：見えるファイルツリー ^t0000043

uts / ipc / user：ホスト名・プロセス間通信・ユーザー ^t0000045

実体：/proc/<pid>/ns/ に net・pid などが並ぶ ^t0000046

[[cgroups]]
CPU 時間・メモリ量などに上限をかける ^t0000049

CPU：--cpus（使える割合を制限） ^t0000051

メモリ：--memory（超えると OOM Kill） ^t0000053

ディスク I/O：読み書きの速さを制限 ^t0000055

PID 数：--pids-limit（暴走を防ぐ） ^t0000057

実体：/sys/fs/cgroup/ 以下の設定ファイル ^t0000058

[[コンテナのファイルシステム]]
書き込みの行き先を決める ^t0000061

イメージ層：読み取り専用（OverlayFS） ^t0000063

コンテナ層：書き込める。コンテナを消すと消える ^t0000065

[[ボリューム]]：Docker が管理し、消しても残る ^t0000067

バインドマウント：ホストのフォルダを共有する ^t0000069

実体：/var/lib/docker/ 以下（overlay2・volumes） ^t0000070

[[コンテナの権限]]
root の力を必要な分だけ渡す ^t0000073

capabilities：root の権限を細かく分けて渡す ^t0000075

seccomp：使えるシステムコールを制限する ^t0000077

user 名前空間：中の root をホストの一般ユーザーに対応させる ^t0000079

--privileged：制限をほぼ外す（危険） ^t0000081

前提：コンテナはホストとカーネルを共有している ^t0000082

Docker / OCI の層：カーネルの機能をどう使うか ^t0000083

runc が名前空間と cgroups を設定してコンテナを起動する。OCI という標準の仕様に沿っているので、Kubernetes でも同じイメージが動く。 ^t0000084

[[コンテナイメージ]]
層を積んで配布する ^t0000087

Dockerfile：1つの命令が1つの層になる ^t0000089

ビルドキャッシュ：変更した層から下だけ作り直す ^t0000091

マルチステージ：ビルド用と実行用でイメージを分ける ^t0000093

レジストリに置いて配布する → [[コンテナレジストリ]] ^t0000095

実務：ビルドが遅い・イメージが大きいときはここ ^t0000096

[[コンテナランタイム]]
誰がコンテナを起動するか ^t0000099

docker CLI：コマンドを受け付ける ^t0000101

dockerd：API を受け付けて全体を管理する ^t0000103

containerd：イメージとコンテナを管理する ^t0000105

runc：名前空間と cgroups を設定して起動する ^t0000107

実務：Kubernetes は dockerd を通らず containerd を直接使う → [[オーケストレーション]] ^t0000111

[[コンテナのライフサイクル]]
起動から停止まで ^t0000114

PID 1：最初のプロセスが終わるとコンテナも止まる ^t0000116

docker stop：SIGTERM、止まらなければ10秒後に SIGKILL → [[グレースフルシャットダウン]] ^t0000118

ログ：標準出力に出す（docker logs で読める） ^t0000120

restart：落ちたときに起動し直す方針 ^t0000122

実務：止まらない・ログが出ないときはここ ^t0000123

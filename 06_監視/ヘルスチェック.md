# ヘルスチェック

ロードバランサーなどが、決まった間隔でアプリの特定のパス（`/health` など）に HTTP リクエストを送り、決まったステータスコード（200 など）を返したサーバーにだけ、リクエストを転送する仕組み。

## なぜ必要か

サーバーを複数台にしても、止まった1台にリクエストを送り続けていては意味がありません。ロードバランサーが **どのサーバーに送ってよいか** を知るための仕組みがヘルスチェックです。

デプロイのときにも使われます。新しい版が起動しても、本当にリクエストを処理できる状態になったかは分かりません。ヘルスチェックに通ったことを確かめてから、古い版を止めます → [[ローリング更新]]

## 仕組み

```txt
ロードバランサー ──GET /health──▶ サーバー1  200 OK   → 送ってよい
                ──GET /health──▶ サーバー2  500      → 失敗1回目
                ──GET /health──▶ サーバー2  応答なし  → 失敗2回目 → 送らない
```

決める値は、おおむね次の4つです。

| 値 | 意味 |
|---|---|
| 間隔 | 何秒おきに問い合わせるか |
| タイムアウト | 何秒で応答が無ければ失敗とするか |
| 異常とみなす回数 | 何回続けて失敗したら外すか |
| 正常に戻す回数 | 外したものが、何回続けて成功したら戻すか |

外れるまでの時間は「間隔 × 異常とみなす回数」、戻るまでの時間は「間隔 × 正常に戻す回数」が目安です。

## 前後のつながり

[[ロードバランサー]] → **ヘルスチェック** → 転送先にするかどうか → [[オーケストレーション]] が入れ替えを進める

## 設計で決めること

### 1. 何を確かめるか
- 選択肢：プロセスが応答できるかだけ（軽い）／DB や外部のサービスまで繋がるか（重い）
- 判断の基準：多くの場合は軽いものにする。重いものは、ヘルスチェック自体が DB の負荷になり、**DB が少し遅くなっただけで全部のサーバーが外れて、サービス全体が止まる** ことがある。DB の異常は、メトリクスとアラートで別に検知する

| 種類 | 良い点 | 困る点 |
|---|---|---|
| 軽い | 速く、負荷が無い | DB が止まっていても「正常」になる |
| 重い | 本当に処理できるか分かる | DB が一時的に遅いだけで全部が外れる |

### 2. どこまで届くパスにするか
- 選択肢：Web サーバーだけが答えるパス／アプリのコードまで届くパス
- 判断の基準：アプリのコードまで届くパスにする。Nginx + PHP-FPM の構成で静的なファイルを確かめると、Nginx だけが応答して PHP-FPM が止まっている状態を見逃す

### 3. 間隔と回数をいくつにするか
- 選択肢：短く・少なく（早く外す）／長く・多く（一時的な遅れで外さない）
- 判断の基準：一時的な遅れで外れすぎるなら回数を増やす。デプロイが遅いなら、戻すまでの回数や間隔を見直す

### 4. 口をどう用意するか
- 選択肢：フレームワークの用意したものを使う／自分で作る
- 判断の基準：Laravel 11 以降は、標準で `/up` というパスがある。Go は自分でハンドラを1つ作る。どちらも、ログイン必須や IP の制限の対象から外しておく

```go
mux.HandleFunc("/health", func(w http.ResponseWriter, r *http.Request) {
    w.WriteHeader(http.StatusOK)
})
```

## 障害

| 症状 | 原因 | 確かめ方 |
|---|---|---|
| アプリは動いているのに「異常」になる | パスやポートがアプリと合っていない、ログインが必要なページを指している、通信の許可が無い | ロードバランサーが問い合わせているパスを、自分でも叩いてみる。新しく構成を作ったときに最も起きやすい |
| デプロイが終わらない | 新しい版がヘルスチェックに通らない | 新しい版の起動時のログを見る。起動に時間がかかるなら、起動直後の失敗を数えない設定を見る |
| DB が少し遅くなっただけで全部止まった | ヘルスチェックで DB まで確かめていた | ヘルスチェックの中身を見る |

## 実装の例

| 環境 | 実装 |
|---|---|
| オンプレ | HAProxy や専用のロードバランサーの機器のヘルスチェック、Kubernetes の readinessProbe |
